ความสามารถ

ครบทุกอย่างที่งานรีโมทต้องใช้

ควบคุมหน้าจอ

เห็นหน้าจอและควบคุมเมาส์กับคีย์บอร์ดแบบเรียลไทม์ รองรับหลายจอ ปรับคุณภาพภาพตามความเร็วเน็ตได้

ส่งไฟล์สองทาง

รับส่งไฟล์และโฟลเดอร์ระหว่างสองเครื่องโดยตรง มีคิวงานและแถบความคืบหน้า

คลิปบอร์ดร่วมกัน

คัดลอกข้อความจากเครื่องหนึ่งไปวางอีกเครื่องได้ทันที

เข้าถึงแบบไม่มีคนเฝ้า

ตั้งรหัสผ่านถาวรไว้ที่เครื่องปลายทาง แล้วเข้าไปดูแลได้แม้ไม่มีใครอยู่หน้าเครื่อง

แชทระหว่างช่วยเหลือ

พิมพ์คุยกับผู้ใช้ปลายทางในหน้าต่างเดียวกันระหว่างแก้ปัญหา

ยืนยันตัวตนสองชั้น

เปิด 2FA เพิ่มได้สำหรับเครื่องที่ต้องการความปลอดภัยสูง และกำหนดสิทธิ์ของผู้ควบคุมได้ทีละข้อ

หน้าตาโปรแกรม

ออกแบบใหม่ให้ใช้ง่ายในภาษาไทย

ID และรหัสผ่านอยู่บนแถบหัวที่เห็นชัด ทุกเมนูมีข้อความกำกับ ไม่ต้องเดาจากไอคอน

เริ่มใช้งาน

สามขั้นตอนก็เชื่อมต่อได้

  1. 1

    ติดตั้ง UDesk

    ติดตั้งทั้งเครื่องที่จะควบคุมและเครื่องปลายทาง

  2. 2

    บอก ID และรหัสผ่าน

    เครื่องปลายทางบอกเลข ID 9 หลักและรหัสผ่านครั้งเดียวบนแถบหัวของโปรแกรม

  3. 3

    กดเชื่อมต่อ

    กรอก ID แล้วกดเชื่อมต่อ ปลายทางกดยอมรับ ก็เริ่มทำงานได้

ความปลอดภัย

ข้อมูลระหว่างสองเครื่อง มีแค่สองเครื่องที่อ่านได้

  • เข้ารหัสตลอดเส้นทางภาพหน้าจอ การกดแป้น คลิปบอร์ด และไฟล์ ถูกเข้ารหัสระหว่างสองเครื่อง เซิร์ฟเวอร์ทำหน้าที่จับคู่และส่งต่อเท่านั้น
  • ต่อตรงเมื่อทำได้ถ้าเครือข่ายเอื้อ สองเครื่องจะคุยกันโดยตรง ไม่ผ่านเซิร์ฟเวอร์
  • มีแถบแจ้งเมื่อถูกควบคุมเครื่องปลายทางเห็นตลอดว่าใครเชื่อมต่ออยู่ และตัดการเชื่อมต่อได้ทันที
