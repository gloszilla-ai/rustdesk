ข้อมูลที่ UDesk บันทึก

UDesk บันทึกข้อมูลการใช้งานเพื่อดูแลระบบและตรวจสอบย้อนหลัง ได้แก่

  • การเปิดโปรแกรม: ID เครื่อง เวอร์ชัน ระบบปฏิบัติการ และเวลา
  • การเชื่อมต่อ: ID ต้นทางและปลายทาง ประเภทการเชื่อมต่อ เวลาเริ่ม และระยะเวลา
  • อีเมลและรหัสบัญชี Google เฉพาะเมื่อคุณเลือกเข้าสู่ระบบ

ข้อมูลที่ UDesk ไม่บันทึก

  • รหัสผ่านทุกชนิด
  • ภาพหน้าจอและวิดีโอของการรีโมท
  • การกดแป้น คลิปบอร์ด และเนื้อหาไฟล์

การเข้ารหัส

ภาพหน้าจอ การกดแป้น คลิปบอร์ด และไฟล์ ถูกเข้ารหัสระหว่างสองเครื่อง เซิร์ฟเวอร์ของ UDesk ทำหน้าที่จับคู่ ID และส่งต่อข้อมูลที่เข้ารหัสแล้วเท่านั้น
