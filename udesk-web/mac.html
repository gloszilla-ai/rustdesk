การให้สิทธิ์บน macOS

macOS ต้องให้คุณอนุญาตก่อน UDesk จึงจะแสดงหน้าจอและรับเมาส์กับแป้นพิมพ์จากอีกเครื่องได้ ทำครั้งเดียวหลังติดตั้ง ถ้าใช้ UDesk เพื่อควบคุมเครื่องอื่นอย่างเดียว ให้สิทธิ์ข้อ 3 ข้อเดียวก็พอ

ก่อนเริ่ม

ลาก UDesk ไปไว้ในโฟลเดอร์ Applications แล้วเปิดจากที่นั่น เมื่อยังขาดสิทธิ์ หน้าหลักของ UDesk จะมีแถบสีส้มพร้อมปุ่ม "ปรับแต่งค่า" กดแล้ว macOS จะเปิดหน้าตั้งค่าที่ถูกต้องให้

1. การบันทึกหน้าจอ (Screen Recording)

ให้เครื่องอื่นเห็นหน้าจอของเครื่องนี้

  • เปิด การตั้งค่าระบบ → ความเป็นส่วนตัวและความปลอดภัย → การบันทึกหน้าจอและเสียงของระบบ
  • เปิดสวิตช์ของ UDesk ถ้าไม่มีในรายการ กด + แล้วเลือก UDesk จากโฟลเดอร์ Applications
  • ออกจาก UDesk แล้วเปิดใหม่

2. การช่วยการเข้าถึง (Accessibility)

ให้เครื่องอื่นควบคุมเมาส์และแป้นพิมพ์ของเครื่องนี้

  • เปิด การตั้งค่าระบบ → ความเป็นส่วนตัวและความปลอดภัย → การช่วยการเข้าถึง
  • เปิดสวิตช์ของ UDesk

3. การตรวจสอบอินพุต (Input Monitoring)

ให้ UDesk ส่งปุ่มลัดของแป้นพิมพ์ไปยังเครื่องที่คุณควบคุม

  • เปิด การตั้งค่าระบบ → ความเป็นส่วนตัวและความปลอดภัย → การตรวจสอบอินพุต
  • เปิดสวิตช์ของ UDesk

ถ้าเปิดสวิตช์แล้วแถบสีส้มยังอยู่

  • ออกจาก UDesk ให้สนิท (คลิกขวาที่ไอคอนบนแถบเมนู → ออก) แล้วเปิดใหม่
  • ถ้ายังไม่หาย ลบ UDesk ออกจากรายการด้วยปุ่ม − แล้วเพิ่มกลับด้วยปุ่ม + มักจำเป็นหลังอัปเดตเวอร์ชัน
