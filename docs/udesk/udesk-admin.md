# UDesk — โหมดผู้ดูแล (admin build)

ตัวติดตั้งแยกสำหรับเครื่องสำนักงานที่ผู้ดูแลเป็นเจ้าของ ให้ผู้ดูแลรีโมทเข้าได้แบบเงียบ
(ไม่มีกล่องแจ้ง ไม่มีตัวนับเวลา) ด้วยรหัสผ่านถาวรที่ฝังไว้ตอน build

## หลักการ

- เครื่องสำนักงาน (ปลายทาง): ลง **admin build** เท่านั้น
- เครื่องของผู้ดูแล (ตัวคุม): ลง **ตัวปกติ** แล้วเชื่อมต่อออกไปตามปกติ — ไม่ต้องลง admin build
  เพื่อไม่ให้เครื่องผู้ดูแลกลายเป็นเป้าหมายที่ถูกเข้าแบบเงียบ

## admin build ทำอะไร (ฝั่งปลายทาง)

เมื่อ build ด้วย `--dart-define UDESK_ADMIN=1` โปรแกรมจะตั้งค่าให้เองทุกครั้งที่เปิด:

- `approve-mode = password` → รับการเชื่อมต่อเองเมื่อรหัสผ่านถูก ไม่มีหน้าต่างให้กดรับ
- `verification-method = use-permanent-password` → ใช้รหัสผ่านถาวร (รหัสครั้งเดียวไม่แสดง)
- ตั้งรหัสผ่านถาวรเป็นค่า `UDESK_ADMIN_PASSWORD` ที่ฝังไว้ (ตั้งใหม่ทุกครั้งที่เปิด กันคนแก้)
- `ServerModel.hideCm = true` → หน้าต่าง connection manager ไม่แสดง (ไม่มีกล่อง ไม่มีตัวนับเวลา)

**ยังบันทึก log เข้าส่วนกลาง** (`UdeskLog`) ทุกการเชื่อมต่อ เพื่อให้ตรวจสอบย้อนหลังได้
เงียบคือเงียบต่อผู้ใช้เครื่อง ไม่ใช่ไม่บันทึก

## วิธี build ตัวติดตั้ง admin (Windows)

1. แก้รหัสผ่านใน `D:\udesk-tools\udesk-admin-secrets.json` (สร้างอัตโนมัติครั้งแรกพร้อมรหัสสุ่ม)
   ```json
   {"UDESK_GOOGLE_CLIENT_SECRET":"...","UDESK_ADMIN":"1","UDESK_ADMIN_PASSWORD":"รหัสที่ตั้งเอง"}
   ```
2. รัน `D:\udesk-tools\build-admin.bat`
3. ได้ `D:\udesk-tools\dist\UDesk-Admin-1.0.4-install.exe` — ติดตั้งบนเครื่องสำนักงาน

**ห้ามเอาตัวติดตั้ง admin ขึ้นเว็บสาธารณะ** และเก็บไฟล์ secrets ไว้เป็นความลับ

## ข้อควรรู้ด้านความปลอดภัย/ความเป็นส่วนตัว

- รหัสผ่านที่ฝังอยู่ในไบนารีถอดได้ด้วยการ reverse engineering ใช้รหัสยาวและไม่ซ้ำที่อื่น
  เปลี่ยนรหัสด้วยการแก้ไฟล์ secrets แล้ว build ใหม่ แจกทับ
- ใครรู้ ID + รหัสนี้เข้าถึงเครื่องได้ถึงหน้าล็อกอิน ควรจำกัดการแจกจ่ายตัวติดตั้งนี้
- **องค์กรควรแจ้งพนักงาน**ว่าไอทีเข้าถึงเครื่องได้ ตามนโยบาย/กฎหมายการเฝ้าดูที่ทำงาน
  (เป็นเรื่ององค์กรต้องทำ ไม่ใช่ตัวโปรแกรม)

## ยังไม่ได้ทำ / TODO

- **ยังไม่ได้ทดสอบจริง**: ยังไม่ได้ติดตั้ง admin build แล้วลองรีโมทเข้าแบบเงียบ (ตั้งใจไม่ลงบนเครื่อง dev)
- **macOS**: ฝั่ง Mac ต้องทำ admin build ของตัวเอง (โค้ด `kUdeskAdmin`/`UdeskAdmin.bootstrap`/`hideCm`
  เป็นของกลางใช้ได้ทั้งสองระบบ ตัว build pipeline ของ .dmg ต้องส่ง `--dart-define UDESK_ADMIN=1`
  และรหัสผ่านเอง) — ดู CHAT-LOG
- ตัวเลือกเสริมที่ยังไม่ทำ: ล็อกออปชันไม่ให้ผู้ใช้เครื่องแก้ (HARD_SETTINGS), จำกัดเฉพาะ LAN
