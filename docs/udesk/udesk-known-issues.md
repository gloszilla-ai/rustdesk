# UDesk: ปัญหาที่รอแก้

รายการที่ผู้ใช้แจ้งระหว่างไล่ตรวจโปรแกรม จดไว้ที่นี่แล้วแก้รวมรอบเดียว

## 2. ระบบอัปเดตในโปรแกรมยังไม่เคยทดสอบกดจริง

- โค้ดอยู่ใน `flutter/lib/udesk/udesk_update.dart` และ `udesk-web/version.json`
- ยังไม่ได้พิสูจน์: แถบสีส้มขึ้นเมื่อมีรุ่นใหม่กว่า, กด "อัปเดต" แล้วโหลด ตรวจ SHA-256
  และเปิดหน้าติดตั้งได้, ติดตั้งทับขณะโปรแกรมเปิดอยู่แล้วกลับมาใช้งานได้
- แผน: ออกรอบแก้รวมเป็น 1.0.1 (แก้ `kUDeskVersion` และ `version.json`) แล้วให้เครื่องที่ลง
  1.0.0 ตัวล่าสุดกดอัปเดตจริง เก็บ `UDesk-1.0.0-install.exe` ไว้ในหน้าเวอร์ชันทั้งหมด

## 1. เปิดโปรแกรมแล้วค้างที่ "ไม่พร้อมใช้งาน" ต้องปิดแล้วเปิดใหม่

- พบเมื่อ: 2026-11-27, Windows, UDesk 1.0.0, เครื่องอยู่นอกวงแลน
- อาการ: แถบสถานะขึ้นสีแดง "ไม่พร้อมใช้งาน กรุณาตรวจสอบการเชื่อมต่ออินเทอร์เน็ตของคุณ"
  ช่องรหัสผ่านครั้งเดียวค้างที่ "กำลังสร้าง…" และลายนิ้วมือในหน้าเกี่ยวกับว่าง
  ออกจากโปรแกรมแล้วเปิดใหม่จึงขึ้น "พร้อม"
- สิ่งที่ยืนยันแล้ว: ไม่ใช่ปัญหาเซิร์ฟเวอร์ ใน log ของ hbbs เครื่องนั้นลงทะเบียนเข้ามาจาก IP ภายนอกได้
  และพอร์ต TCP 21115–21117 เปิดจากภายนอก
- สมมติฐาน (ยังไม่ได้พิสูจน์): หน้าต่างหลักเปิดก่อนที่บริการเบื้องหลังจะเริ่มเสร็จหลังติดตั้งทับ
  หน้าต่างจึงต่อ IPC ไม่ได้และไม่ลองใหม่เอง อีกทางหนึ่งคือเครื่องเพิ่งย้ายเครือข่ายแล้วสถานะไม่รีเฟรช
- ยังไม่รู้: เกิดซ้ำได้ไหมเมื่อไม่ได้เพิ่งติดตั้ง, พอร์ต UDP 21116 จากภายนอกยังไม่ได้ทดสอบ
- ขั้นต่อไป: ทำซ้ำด้วยการติดตั้งทับแล้วเปิดทันที เก็บ log จาก `%APPDATA%\UDesk\log`
  ของเครื่องที่เป็น แล้วดูว่าหน้าต่างหลักลองต่อบริการใหม่หรือไม่
