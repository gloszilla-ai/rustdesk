### 9. ถอดคำว่า RustDesk ที่เหลือออกจากโปรแกรม (ยกเว้นเว็บ) (รีวิว 2026-11-27)

### 10. โหมดผู้ดูแล (admin build) — ขอบเขตสรุปแล้ว (2026-11-27)

เจ้าของงานเลือก: **เงียบทั้งหมด**, เชื่อมต่อ **ทุกที่ผ่านเซิร์ฟเวอร์**, เปิดด้วย **ตัวติดตั้งแยกสำหรับสำนักงาน**

บริบท: เครื่องสำนักงานที่องค์กรเป็นเจ้าของ ผู้ดูแล (เจ้าของงาน) เป็นคนติดตั้งเอง เพื่อดูแลเครื่องตามนโยบายสำนักงาน
เป็น unattended access ที่ถูกต้อง ไม่ใช่สอดแนมบุคคลที่สาม

ออกแบบ:
- **เครื่องแอดมิน (ตัวคุม) ใช้ตัวปกติ**: การเปลี่ยนแปลงของ admin build อยู่ที่ฝั่งรับการเชื่อมต่อเท่านั้น
  (silent/auto-accept) เครื่องของแอดมินที่เป็นคนเชื่อมต่อออกไปใช้ตัวติดตั้งปกติ ไม่ต้องลง admin build
  เพื่อไม่ให้เครื่องแอดมินกลายเป็นเป้าหมายที่รับการเชื่อมต่อแบบเงียบ (เจ้าของงานกำชับ 2026-11-27)
- **build แยก**: ใช้ build-time flag (เช่น `--dart-define=UDESK_ADMIN=1` + ฝังใน config) ตัวติดตั้งปกติต้องไม่เงียบ
  ตัวติดตั้ง admin ตั้งชื่อ/ไฟล์ให้ต่างชัดเจน (เช่น `UDesk-Admin-x.y.z-install.exe`) ไม่ขึ้นหน้าเว็บสาธารณะ
- **เงียบทั้งหมดบนเครื่องปลายทาง**: ไม่ขึ้นหน้าต่าง connection manager, ไม่มีตัวนับเวลา, auto-accept
  (ดู `src/server/connection.rs`, `ui_cm_interface.rs`, `flutter/lib/desktop/pages/server_page.dart`,
  `approve-mode`/permanent password) — เป็นงานฝั่ง Rust ด้วย ไม่ใช่แค่ UI
- **ยังคงบันทึก log เข้ากลาง**: เพื่อ accountability ของผู้ดูแล การเข้าถึงทุกครั้งยังถูกบันทึกใน Firestore
  (`udesk_log`) แม้ไม่แสดงบนเครื่องปลายทาง = เงียบต่อผู้ใช้ แต่ตรวจสอบย้อนหลังได้จากส่วนกลาง
- **ความรับผิดชอบ**: องค์กรควรแจ้งพนักงานว่าไอทีเข้าถึงเครื่องได้ ตามนโยบาย/กฎหมายแรงงานของการเฝ้าดูที่ทำงาน
  (เป็นเรื่ององค์กรต้องทำเอง ไม่ใช่ตัวโปรแกรม)
- ไม่ทำให้เลือกเครื่องปลายทางที่เป็นของบุคคลอื่นได้ง่าย: ใช้ได้เฉพาะเครื่องที่ติดตั้ง admin build เองเท่านั้น
### 7. ปุ่มแดง "ยกเลิกการเชื่อมต่อ" ในกล่องมุมขวาบน กดผ่านการรีโมทไม่ได้ (ไม่ใช่บั๊ก เป็นการป้องกันของ upstream)

- ผู้ใช้แจ้งเมื่อ 2026-11-27 ทั้ง Windows และ Mac: ระหว่างรีโมทอยู่ กดปุ่มแดงในกล่อง connection manager แล้วไม่มีอะไรเกิดขึ้น
- สาเหตุ (ยืนยันจากโค้ด): `checkClickTime` ใน `flutter/lib/desktop/pages/server_page.dart` ทิ้งคลิกที่เกิดภายใน 120 ms
  หลังคลิกที่ส่งมาจากฝั่งควบคุม เว้นแต่ตั้งตัวเลือก `allow-remote-cm-modification` (ค่าเริ่มต้นปิด และไม่มีในหน้าตั้งค่า)
  ตั้งใจให้ผู้ที่รีโมทเข้ามาเปลี่ยนสิทธิ์หรือกดปุ่มในกล่องนี้ไม่ได้ กดได้เฉพาะคนที่อยู่หน้าเครื่อง
- ข้อเสนอ (รอผู้ใช้ยืนยัน): เมื่อคลิกถูกทิ้ง ให้ขึ้นข้อความสั้น ๆ ว่า "ปุ่มนี้กดได้เฉพาะที่หน้าเครื่อง"
  ไม่ควรเปิด `allow-remote-cm-modification` เป็นค่าเริ่มต้น เพราะเป็นการลดการป้องกัน

### 1. เปิดโปรแกรมแล้วค้างที่ "ไม่พร้อมใช้งาน" ต้องปิดแล้วเปิดใหม่

- พบเมื่อ: 2026-11-27, Windows, UDesk 1.0.0, เครื่องอยู่นอกวงแลน
- อาการ: แถบสถานะขึ้นสีแดง "ไม่พร้อมใช้งาน กรุณาตรวจสอบการเชื่อมต่ออินเทอร์เน็ตของคุณ"
  ช่องรหัสผ่านครั้งเดียวค้างที่ "กำลังสร้าง…" และลายนิ้วมือในหน้าเกี่ยวกับว่าง
  ออกจากโปรแกรมแล้วเปิดใหม่จึงขึ้น "พร้อม"
- สิ่งที่ยืนยันแล้ว:
  - ไม่ใช่ปัญหาเซิร์ฟเวอร์: ใน log ของ hbbs เครื่องนั้นลงทะเบียนจาก IP ภายนอกได้หลังเปิดใหม่
    และพอร์ต TCP 21115–21117 เปิดจากภายนอก
  - รหัสผ่านค้าง "กำลังสร้าง…" แปลว่าหน้าต่างหลักต่อ IPC กับโปรเซส `--server` ไม่ได้เลย
  - โค้ดฝั่ง Rust (`check_connect_status_` ใน `src/ui_interface.rs`) วนต่อ IPC ใหม่เองอยู่แล้ว
    ดังนั้นสาเหตุไม่ใช่ "หน้าต่างไม่ลองใหม่" น่าจะเป็นโปรเซส `--server` ไม่ได้ทำงานอยู่ตอนนั้น
- ยังไม่รู้: ทำไมโปรเซส `--server` ไม่ทำงาน (หลังติดตั้งทับ? หลังย้ายเครือข่าย?) และพอร์ต UDP 21116
  จากภายนอกยังไม่ได้ทดสอบ
- ต้องการเพื่อไปต่อ: log จากเครื่องที่เป็นตอนเกิดอาการ ที่ `%APPDATA%\UDesk\log` และ
  `C:\Windows\ServiceProfiles\LocalService\AppData\Roaming\UDesk\log` ยังไม่ได้แก้โค้ดเพราะยังไม่รู้สาเหตุ

### 7. macOS: สิ่งที่ยังไม่ได้ทดสอบหลัง build ครั้งแรก

- 2026-11-27 build 1.0.3 ได้ทั้ง arm64 และ x86_64 เปิดบน Apple Silicon แล้วขึ้น "พร้อม"
- ทดสอบแล้วโดยเจ้าของงาน: Google login, รีโมทออกไปเครื่อง Windows (มีภาพเดสก์ท็อปบนการ์ด)
- แถบส้ม "ติดตั้งเซอร์วิส" ไม่หายหลังติดตั้ง: แก้แล้วใน build 1.0.3 รอบสอง (`get_full_name()`) รอเจ้าของงานยืนยัน
- ยังไม่ได้ทดสอบ: รีโมทเข้าเครื่อง mac, แถบส้มขอสิทธิ์และปุ่ม "ปรับแต่งค่า",
  การโหลดและเปิด `.dmg` จากปุ่มอัปเดตในโปรแกรม, ตัว x86_64 บนเครื่อง Intel จริง
  (ทดสอบแค่ `--version` ผ่าน Rosetta), ไอคอน tray บนแถบเมนู
- arm64 ใช้ Flutter 3.24.5 ซึ่ง upstream รายงาน crash ตอนพิมพ์ด้วย IME (rustdesk#16817) ยังไม่ได้ลองกับภาษาไทย
- ไอคอน tray เป็นเงาของโลโก้ที่สร้างอัตโนมัติ ถ้ามีไฟล์เวกเตอร์ตัว U ควรวาดใหม่
